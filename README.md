# 🏨 CerHotel | Luxury Stay Website

CerHotel is a premium, luxury-concept hotel website built using modern web technologies. With its elegant design, user-friendly interface, and fully responsive layout, it aims to deliver a high-end digital experience for sophisticated stay concepts.

---

## ✨ Features

* **Premium Design:** Curated typography, an elegant color palette, and gold/bronze accents tailored for a luxury hospitality vibe.
* **Fully Responsive:** Flawless layout and viewing experience across desktops, tablets, and mobile devices.
* **Interactive Elements:** Dynamic navigation transitions, modern room and suite showcasing cards, and custom video overlay sections.
* **SEO & Performance Optimized:** Built with semantic HTML5 tags and clean CSS for optimized loading times and structure.
